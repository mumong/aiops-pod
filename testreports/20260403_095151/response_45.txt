**1. [优先] 修正 Elasticsearch 配置**

```
*依据*：根因是配置错误，必须修正以恢复集群健康。

**2. [其次] 验证 Elasticsearch 集群健康状态**
等待 Elasticsearch Pod 重启后，验证其状态。
```bash

```
*预期结果*：`"status" : "green"` 或 `"yellow"`，且 `"unassigned_shards" : 0`。

**3. [最后] 清理并重试 Kibana 预安装作业**
Elasticsearch 恢复后，删除失败的 Job/Pod 以触发重新执行。
```bash

kubectl delete pod pre-install-observability-kibana-477c7 -n xnet

# 或者，找到并删除对应的 Job
kubectl get job -n xnet | grep pre-install-observability-kibana
kubectl delete job <job-name> -n xnet
```
*目的*：让控制器重新创建资源，执行成功的初始化。
