```bash
# 1. 找到控制器

# 2. 假设是 Deployment，编辑其配置
kubectl edit deployment logfill -n aiops-e2e
```
在编辑器中，找到 `volumes` 部分下名为 `logs` 的 `emptyDir` 定义，将 `sizeLimit` 调整为一个更大的值，例如 `200Mi` 或 `1Gi`（根据应用实际需求判断）。
```yaml
# 修改前
volumes:
- name: logs
  emptyDir:
    sizeLimit: 30Mi
# 修改后
volumes:
- name: logs
  emptyDir:
    sizeLimit: 1Gi
```
保存退出后，Kubernetes 会滚动更新 Pod。

**2. [可选] 清理已被驱逐的 Pod**
