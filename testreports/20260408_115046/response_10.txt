### 立即执行（按优先级排序）
**1. [优先] 诊断节点网络连通性**
在Pod所在节点 `node2` 上执行以下命令，测试到 Docker Hub 的连接：
```bash
# 1. 测试基础连通性 (可能需要安装 curl/telnet)

# 2. 检查网络代理设置

```
*目的*：确认网络断点，判断是节点策略、代理问题还是外部网络问题。

**2. [可选] 使用可访问的镜像或私有仓库**
如果网络问题无法立即解决，可临时修改Pod配置，使用已缓存的镜像或内部私有仓库：
```bash

```
*依据*：绕过有问题的外部仓库，使应用尽快恢复。
