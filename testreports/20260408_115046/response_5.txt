```bash

```
如果确认是网络策略问题，创建或修改策略以允许egress流量。
```yaml
# 示例：允许所有Pod访问外部DNS和HTTPS
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: allow-egress-external
  namespace: aiops-e2e
spec:
  podSelector: {}
  policyTypes:
  - Egress
  egress:
  - ports:
    - port: 53
      protocol: UDP
    - port: 53
      protocol: TCP
  - ports:
    - port: 443
      protocol: TCP
  - to:
    - ipBlock:
        cidr: 0.0.0.0/0
```

**2. [关键] 在故障节点上执行网络诊断**
登录到节点 `node2` (IP: 10.2.0.50)，执行以下命令：
