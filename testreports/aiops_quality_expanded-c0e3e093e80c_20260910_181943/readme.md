## 四项指标怎么得到

- 根因准确率：脚本从报告提取根因陈述，与场景预期匹配，按保存的单次 accuracy 求平均；不是人工评分。
- Runbook 覆盖率：报告引用的预期 Runbook 数／预期数量，再求平均；不代表实际知识使用质量。
- 证据完整度：每次 Evidence Plan 已采集项／计划项，再求平均；是计划完成比例，不是事实充分性。
- MTTR：每次诊断的 elapsed_seconds 均值，不是实际修复耗时。

请求失败及脚本标记注入失效的运行不进入质量均值；缺失指标不按 0 分处理，须同时看有效样本数。
