```yaml
  "... if [ -z \"${APP_BOOT_MODE:-}\" ]; then
    echo \"FATAL: missing required APP_BOOT_MODE\"
    exit 42
  fi ..."
]
```

**修复建议**：在 Deployment 中添加环境变量，例如：
```yaml
env:
  - name: APP_BOOT_MODE
```
