### 根因结论
**结论**：根据证据 #2（Exit Code 137）和证据 #4（集群中大量容器配置 memory ≤200Mi），  
问题的根本原因是**Kibana 初始化/清理任务的内存限制（memory limit）配置过低（推测为 50Mi~200Mi）**，  
远低于 Kibana 作为 Java 应用的最低运行需求（≥1Gi），导致容器启动后立即触发 OOM Killer 被终止。

**置信度**：高 (85%)

- ✅ Kibana 官方要求 ≥1Gi 内存，50Mi~200Mi 明显不足（行业共识 + 配置证据 #4）  
- ✅ 无其他错误类型（如 ImagePull、NodeNotReady）干扰
