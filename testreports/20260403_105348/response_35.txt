**2. [立即] 为 `memhog` Deployment 增加内存限制（示例）**
```bash

```

**3. [批量修复] 为所有低内存限制的 Deployment 统一设置最小值**
```bash
# 为所有命名空间中 memory limit ≤200Mi 的 Deployment 设置最小 512Mi

  echo "Updating $ns/$name to 512Mi limit"
  kubectl set resources deployment/$name -n $ns --limits=memory=512Mi --requests=memory=256Mi

```
