# 按消费阶段交接诊断结果

状态：已实现并部署；真实诊断、证据回读及测试结果见 [验证记录](history/stage-handoff-validation-20261014.md)。用户已确认独立诊断结果＋简短总览的方向。

## 目标与边界

RCA 交付正式分组诊断，conclusion 只整合小型索引并生成总览。程序保留全部组的结果与状态，前端直接展示各组诊断；修复按稳定 group/target ID 读取该组成果，不解析总览来重建异常。

Agent 决定异常对象、取证、根因、关键事实和是否补读。代码只处理身份一致性、格式、引用归属、预算、结果完整性和展示。正常 Pod 明细在定位结束后不再传给后续阶段；原始归档保留。异常包括 Agent 尚待核实的线索，不按 phase 或故障名硬编码过滤。

## 字段逐项审计与目标归属

| 现有字段 | 后续消费者/价值 | 处理 |
|---|---|---|
| question/original_question | 各阶段任务约束 | 全局保存一份原问题；分支另加自己的 task，不重复整段原问题 |
| request_contract/original_request_contract | 范围、只读/任务语义 | 全局原范围＋分支对象范围；不是操作授权的替代品 |
| request_time_utc/run_id | 时效、追溯 | 全局元数据；按需投影给消费者 |
| coverage/pod_assessment | 正常提前结束、检查缺口 | 保留范围、覆盖状态、缺口、总体判断；不带正常明细 |
| lifecycle_core/entities/record_sets | 定位时的现场输入 | 不再作为全局不可压缩内容；后续仅异常对象必要事实进入交接 |
| targets/target_id/entity/uid | 分组不漏对象、防混淆实例 | 稳定 ID 和实体保留；全量目标目录在状态/结果库，分支只收到自己的目标 |
| issue/status/status_reason | 当前要查什么、是否已处置 | 定位→采证保留；后续由本组成果记录明确状态 |
| facts | 支撑判断、修复前提 | Agent 选择少量关键事实与真实引用；完整工具返回及其他事实走普通压缩/归档 |
| previous_fact_id/历史事实版本 | 审计，而非每次推理必要信息 | 保存在归档；不自动追加到下一阶段保护 JSON |
| findings/certainty | 根因是否已证实 | RCA 输出保留判断与支持引用；不自动保留每轮旧判断 |
| unknowns/limitations/冲突 | 防止过度断言、修复补证 | 当前未解决项保留，已解决历史不永久累加 |
| next_questions | 采证下一步线索 | 进入采证可保留；RCA/总览不继承已经完成的任务列表 |
| runbook_refs/shared_runbooks | 自主补读指导 | 本组相关引用；不跨组广播手册全文，不构成新授权 |
| shared_location_notes/layer_analysis | 背景说明 | 分支用本组问题替代全局长草稿；必要文字进入普通压缩 |
| evidence_analysis/query_draft | 当前阶段分析 | 采证→RCA 普通可压缩文字；RCA 成果发布后不再送给 conclusion |
| rca_analysis | 分组正式诊断 | 完整保存、展示并交给对应修复组；总览仅收到索引 |
| observations/recent_interactions | 日志/指标/配置等现场证据 | 本组采证与 RCA 使用；不上传整包到 conclusion；其预算来自实际剩余空间 |
| evidence_receipts/raw_ref/structured_ref | 找回原证据 | 完整目录存储；保护区仅保留选中事实所引用的地址，不全量重复列表 |
| parallel_inventory | 任务完整性对账 | 程序管理；分支不携带兄弟任务，总览按预算读取索引 |
| parallel_results/material | 当前最大汇总来源 | 改为独立成果与引用，不传分支工作历史 |
| execution_incomplete/status/error | 失败不能伪装成功 | 结构化短状态与缺口保留；完整堆栈归档 |
| session_history/working_summary | 必要历史上下文 | 普通摘要，不属于无上限保护区 |

## 流程与职责

1. 定位输出可压缩分析＋异常清单。覆盖信息留在全局；有效异常清单用于建组。
2. 分支使用显式投影而不是复制父工作上下文：本组对象、线索、任务范围、选中证据引用。采证自主补查。
3. 采证输出可压缩分析＋有限关键事实；RCA 能读本组证据并提交正式结果。完整正文保留，不自动累加旧事实。
4. 分组结果独立持久化。程序核对计划 ID 与结果 ID，失败/缺失明确列出；不能因总览省略而消失。
5. conclusion 按实际预算读取小索引。超预算分批处理索引，不压缩/覆盖正式诊断成果；整体统计由程序计算。总览失败时仍展示各组结果。
6. 修复从结果库取指定组成果、关键证据/未知项和 Runbook 引用。保留现有组内反馈、审批和执行边界；老记录兼容读入，不自动执行。
7. 前端展示简短总览和分组诊断卡片；全量结构化结果可供 API/A2A 消费，不依赖前端解析 Markdown。

## 预算原则

存储不等于注入。所有模型请求按提示词＋schema＋本阶段保护数据＋可压缩文本＋输出预留统一计量。结果字段数量/长度受 schema 约束；超限不静默截断事实或对象，标记交付不完整并保留原始输出。正常 Pod 明细不纳入下游保护区。总览不得再将分组全文作为摘要输入。
