# Pod 异常检测边界与验证（2026-10-13）

## 行为约定

- 深度诊断默认检查目标范围的 Pod，而非全栈集群体检。
- Running 不等于健康；近期 10 分钟重启、未就绪、删除阻塞等线索由 Agent 判断并调查。
- 窗口外的累计重启和旧终止记录本身不触发调查；历史数据不完整不等同于当前异常。
- healthy 表示本次检查未发现当前或可见近期未解决的 Pod 异常，不保证完整历史或业务绝对健康。
- Agent 决定目标、证据与诊断；代码检查健康声明与覆盖范围、未解决目标、实际引用、工具失败和未完成分页是否一致。
- 无待调查目标可从定位直接进入结论；存在目标保留现有单组/并发采证与 RCA。
