# 指标解读与展示优化 — 2026-10-10

## 本轮边界

- 后端共享 `METRIC_EVIDENCE_GUIDANCE`：快速查询、深度定位/取证、RCA、总结结合表达式、指标名、原始标签、数值、单位和时间判断。0/1 的语义由指标定义决定；不把抓取失败直接升级为组件宕机，不把同源告警当成独立佐证。
- 前端两类指标结果统一展示关键标签；数值在标签之前，工具名与摘要分行，在桌面和窄屏自动换行。预览最多三条记录、每条六个标签；标签值超过 72 字符显示省略号，明确披露额外记录/标签数量，展开详情保留原有完整标签。
- 标签优先级仅影响 UI 预览，不改变模型输入或原始观测。自定义标签同样支持，不按故障名称套模板或推断健康状态。
- 没有修改 MCP 查询/去重、工具摘要、上下文压缩、路由、权限、审批或修复执行；没有改变历史会话存储结构。
