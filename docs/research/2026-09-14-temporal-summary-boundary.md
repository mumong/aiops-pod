# 时序摘要的可判别性：代码验证与专利续查

日期：2026-09-14。状态：真实代码路径 + 合成反例 + 已核读近邻；不是线上误诊复现，也不是已成立的创新方案。

## 1. 本轮回答什么

用户提出“纯规则是不是不一定好用，是否需要 Agent + 小模型”。必须区分：

- 选择问题：面对同一批完整观测，不同诊断任务需要不同信息，模型可以辅助选择。
- 信息损失问题：两个不同原始状态已经被变换为完全相同的输入，任何仅使用该输入的选择器都不能可靠区分。加入小模型本身无法恢复差别，需要取得额外信息。

后一问题提供了比“模型选重要内容”更具体的验证对象：时序关系在独立统计中消失。

## 2. 当前实现中核实的路径

代码探索先尝试 fast-context，因 Windsurf API Key 不可用失败；随后只读核查已定位文件。

MCP `../mcpstander/servers/aiops_observability/query/metrics.py`：

- 约 176—179 行：范围查询将原始样本交给 `_bounded_values`，同时从 `original_values` 计算 `_stats` 和 sample_count。
- `_bounded_values`，约 636 行：截样时保留首尾、最小/最大样本及均匀选取样本；保留下来的样本仍含时间戳。
- `_stats`，约 674 行：返回 first/min/max/last 数值，不返回极值时间。
- `_facts`，约 509 行：范围序列选择末样本作为 point，observed_at 对应该点，stats 另行附带。因此末样本时间不能解释为最大值发生时间。

Agent `app/core/context/observability_projection.py` 的 `_normalize_metric`（约 309 行）复制 stats、value、sample_count 等，未重建各统计值的发生时间。

结论仅限这条统计投影路径。归档中的样本可能保留区别，其他工具和显式 PromQL 也可能直接取得所需信息；不能说系统完全没有时序分析能力。

## 3. 两个可重跑的反例

运行：`python3 docs/research/temporal_summary_feasibility.py`。

脚本通过 AST 提取当前 MCP 的 `_stats` 单个函数运行，不导入服务模块；不调用模型、网络或 Kubernetes。当前 8 个断言测试通过。

### 反例 A：两个峰值是否同一采样点发生

| 时间索引 | A | B：同时 | B：错峰 |
|---|---:|---:|---:|
| 0 | 0 | 0 | 0 |
| 1 | 10 | 10 | 0 |
| 2 | 0 | 0 | 10 |
| 3 | 0 | 0 | 0 |

两种 B 的 first/min/max/last 都是 0/0/10/0，末样本、样本数量相同，但 `存在采样点 A>=9 且 B>=9` 的结果相反。

### 反例 B：即便补上最大值时间，也仍不足够

- A：`[0, 10, 9, 0, 0, 0]`
- B1：`[0, 0, 9, 10, 0, 0]`
- B2：`[0, 0, 0, 10, 9, 0]`

B1/B2 的四项统计、末点、样本数量、最大值时间（索引 3），甚至完整无序数值集合都相同。A 与 B1 在索引 2 同时达到 9，A 与 B2 则没有。

因此，“给峰值加时间戳”只能解决某种特定查询，不是通用的时序关系保留方案。

辅助测试明确：缺样、非有限值、不同采样时间不自动当作否定；拒绝重复时间戳的未定义归并。阳性证据可由一个共同采样点给出，阴性结果需要指定网格的完整覆盖。测试只谈离散样本，不证明连续时间内没有共现，也不证明因果。

## 5. 模型与规则可以怎样分工——拟扩展，不是创新结论

比让模型自由重写观测更可控的一种实施形式：

1. 程序建立观测目录：真实序列 ID、单位、对象、时间范围、可用样本覆盖及源引用。
2. 现有诊断 Agent 或可选小模型提出一个受支持的检查请求，例如 `sampled_overlap(A,B,thresholdA,thresholdB,window)`。阈值必须给出来自配置、用户或探索性假设的来源，不能凭模型选择就称为异常标准。
3. 程序校验序列、单位和时间口径；先判断当前表示是否足够执行该操作。无法判断就返回 unknown，而不是让模型把统计极值当作同时发生。
4. 需要时从归档取得相应样本；归档只有降采样时，不把 sample_count 等同于完整覆盖。源查询补采属于独立、有资源上限的操作，必须区分于归档回读。
5. 程序输出请求参数、离散网格范围、观察到的共同样本及引用，或者覆盖充分的“该网格未观察到”；预算或数据不足则保留 unknown。时间对齐、时钟偏差、重采样必须显式规定，不能默默最近邻匹配。
6. Agent 解释这些结果；程序只验证指定数值关系，不确认“内存导致错误”等因果。请求不受支持、引用不可读、重试或预算耗尽时终止该检查，保留未判定状态。

这是完整的工程操作链草案。上述脚本只验证统计损失和一个离散检查器，**没有实现目录选择模型、按预算恢复循环或服务接入**。

从第一性原理看，先明确要区分的状态，再确定表示是否包含区分信息，比假设摘要天然支持所有判断更严谨。跨领域来源是压缩信号查询和不完备信息下的判定；不能将迁移本身等同于创造性。

## 6. 本轮选择与下一步门槛

本轮产出是“可重复的信息损失证据”，不是又确定了一篇可申请专利。

- 保留小问题：有限观测摘要会消除某些跨时序区别，模型能力提升不能独自解决。
- 不将“补极值时间”“模型选择摘要”“按查询回读”原样列为推荐独立申请点。
- 下一步必须比较有损时序查询、近似查询精化和时序监测的既有机制，寻找其中尚未解决的具体矛盾；尤其要核查上面第 3—5 步是否只是成熟三值判定与自适应查询的常规接合。
- 若无法指出现有方法在相同输入、预算和判定条件下的明确不足，不继续追加模型名称或角色来制造区别。

未修改 Agent、MCP、测试任务、部署和权限。研究总目标仍未完成：新颖性及创造性区别尚缺证据。

### 7.3 不确定观测下的时序逻辑：相关误差不能随意拆开

文献：Finkbeiner、Fränzle、Kohn、Kröger，**A Truly Robust Signal Temporal Logic: Monitoring Safety Properties of Interacting Cyber-Physical Systems under Uncertain Observation**，Algorithms 2022，15(4)，126，[DOI](https://doi.org/10.3390/a15040126)。

核验级别：通过 Crossref 取得出版者登记的标题、作者、出版日期与完整摘要，**本轮没有取得或核读论文算法全文**。

摘要明确描述：将误差分成“未知但固定的偏移”和“独立的逐样本误差”，使用仿射算术及线性算术上的 SMT，能够在逐样本区间估计仍不确定时给出部分确定的监测结果。不能将摘要的算法最优性表述扩展到我们的观测投影问题。

一个用来理解思想的自造例子（不是该论文实验）：两个样本读数为 10、20，二者共享未知固定偏移 b，且 b 在 [-10,10]。真实值分别为 10-b、20-b，因此两点差值确定为 10。如果独立只保留两点区间 [0,20] 与 [10,30]，差值范围却成为 [-10,30]，连是否上升都不能确定。问题不是再多采一条数据，而是共同误差项被拆散。

可借鉴的思考方式：判断不确定性究竟来自缺数据，还是来自表示丢失了共享约束。后者有时可通过保留共同参数解决，无需立即扩大模型输入。

不能直接迁移为结论：我们的输入是有限观测集合，不天然具有上述固定误差模型；若不知道哪些观测共享偏移，就不能让程序或模型凭空赋予这种关系。保留共同误差项本身也已由该论文公开，不是新贡献。

另核到 **Robust Online Monitoring of Signal Temporal Logic**（2015，DOI `10.1007/978-3-319-23820-3_4`）的标题、作者和出版元数据，尚未读其全文，不以此声称具体算法已核实。

### 7.4 续查后的决定

目前的时序草案只适合作为工程基线和问题验证，不升级为推荐主申请：

| 设想操作 | 已核读的近邻启示 | 当前决定 |
|---|---|---|
| 依据问题选表示 | US8219574B2、US10102247B2 | 不单独主张新意 |
| 模型选择/调整表示 | US20260094322A1 | 不靠加入小模型区分 |
| 信息不足时定位局部并恢复 | US8219574B2、US10102247B2 | 需要另外证明非显而易见的处理区别 |
| 保留相关不确定性以提高判定能力 | 2022 年论文摘要 | 有具体跨域启发；需读全文，不能当成空白技术 |

尚未找到一份文献逐项公开我们所有设想，也未证明存在足够的创造性区别。这两句话并不矛盾：不能用多篇文献随意拼接就宣判缺乏新颖性，但这些公开足以要求更强的区别贡献。

下一候选应先提供至少一个反例：在明确的同源输入、预算和查询条件下，现有简化/局部恢复方法仍留下何种不足，拟议操作如何改变该不足。不能只增加 manifest、Agent 或异常名称。

本轮另外只读查看了诊断临时 Pod 工具路径，作为“诊断动作自身产生的观测是否被后续诊断误用”的候选线索；没有核验部署状态、没有实际执行工具、没有认定历史污染全部由该实现导致。该线索不是本时序方案的新特征，是否扩展研究范围已向用户发出可选问题。
