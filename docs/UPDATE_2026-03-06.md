### 3. max_tokens_per_agent=0 不设限逻辑

**实现位置**：`app/core/federation/aggregator.py` - synthesize 方法

**逻辑**：
- `max_tokens_per_agent > 0`：按设定值压缩单个子集群报告
- `max_tokens_per_agent = 0`：不设单个限制，但检测总 token 数
- 总 token 数超过 60000（模型上下文限制）时，强制压缩所有报告

**配置示例**：
```yaml
federation:
  max_tokens_per_agent: 0  # 0=不限制单个子集群
```

### 4. 保存子集群报告

**实现位置**：`app/core/federation/aggregator.py` - _save_reports 方法

**功能**：
- 自动创建 `reports/` 目录
- 每次联邦查询后保存所有成功的子集群报告
- 文件名格式：`{cluster_name}_{timestamp}.md`
- 示例：`cluster-24_20260306_140530.md`

**查看报告**：
```bash
ls -lh reports/
cat reports/cluster-24_20260306_140530.md
```

## 📝 配置说明

### 主集群配置（deploy/configmap/config.yaml）

```yaml
federation:
  enabled: true                    # 主集群设为 true
  max_tokens_per_agent: 22000      # 单个子集群 token 上限（0=不限制）
  synthesis_timeout: 300           # 超时时间（秒）
  sub_agents:
    - name: "cluster-24"
      url: "http://10.2.0.24:30800"
      description: "被管集群"
      enabled: true
```

### 参数说明

| 参数 | 说明 | 默认值 | 推荐值 |
|------|------|--------|--------|
| `max_tokens_per_agent` | 单个子集群报告 token 上限 | 12000 | 22000（0=不限制） |
| `conclusion_max_tokens` | 子集群诊断结论最大 token 数 | 8192 | 8192-16384 |

**max_tokens_per_agent 行为**：
- `> 0`：超过此值的子集群报告会被 LLM 压缩
- `= 0`：不限制单个子集群，但总 token 数超过 60000 时强制压缩

## ⚠️ 注意事项

1. **reports/ 目录**：会自动创建，建议添加到 .gitignore
2. **max_tokens_per_agent=0**：适合子集群数量少（<5个）的场景
3. **模型上下文限制**：DeepSeek 约 64K tokens，系统预留 4K，实际限制 60K
4. **make master/slave**：会自动修改 deploy/configmap/config.yaml，请确认后再提交

## 🔧 技术细节

### Token 压缩逻辑

```python
# 单个子集群压缩
if max_tokens_per_agent > 0 and token_count > max_tokens_per_agent:
    text = compress_single(result)

# 总量超限强制压缩
if total_tokens > 60000:
    for each result:
        text = compress_single(result)
```
