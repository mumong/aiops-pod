# Contract: Ask Conclusion Remediation JSON

## Boundary

This contract applies only to `/ask` conclusion output before it is returned from `ConclusionFormatterNode`.

## Input

- Final Markdown report generated by the conclusion LLM.
- Conclusion input context available in the node: layer analysis, evidence analysis, RCA analysis, and tool data text.
- The current workflow layer.

## Output

- The same Markdown report, optionally with a repaired `## 🧩 结构化修复计划` JSON block.
- No additional LLM call.
- No changes to query output.

## Valid Normalized Finalizer Plan

```json
{
  "remediation_available": true,
  "fix_type": "remove_finalizer",
  "risk_level": "medium",
  "requires_human_approval": true,
  "issue_groups": [
    {
      "group_id": "g1",
      "problem_type": "TerminatingStuck",
      "target": "namespace/pod/name",
      "auto_fixable": true,
      "strategy": "Patch confirmed blocking finalizers, then verify Pod deletion or non-Terminating state."
    }
  ],
  "basis": [
    "Current Pod evidence confirms deletionTimestamp.",
    "Current Pod evidence confirms non-empty metadata.finalizers."
  ],
  "actions": [
    {
      "id": "remove-finalizer-g1",
      "type": "kubectl_patch",
      "group_id": "g1",
      "target_issue": "TerminatingStuck",
      "description": "Remove confirmed blocking Pod finalizers.",
      "risk": "medium",
      "dry_run_command": "kubectl get pod <pod> -n <namespace> -o yaml",
      "execute_command": "kubectl patch pod <pod> -n <namespace> -p '{\"metadata\":{\"finalizers\":null}}' --type=merge",
      "verify_command": "kubectl get pod <pod> -n <namespace>"
    }
  ],
  "stop_conditions": [
    "User rejects approval",
    "Pod evidence no longer matches deletionTimestamp plus finalizers",
    "Patch or verification fails"
  ]
}
```

Placeholders in the example must be replaced with real evidence values before output.
